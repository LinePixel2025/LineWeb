# 网盘前端界面重构设计文档

## 1. 项目概述

### 1.1 项目目标
重构网盘前端界面，解决现有界面的三个主要痛点：
- 文件操作繁琐
- 导航不直观
- 信息展示混乱

### 1.2 设计原则
- 保持 Liquid Glass 设计语言
- 响应式设计，适配所有设备
- 优先支持拖拽、右键菜单、快捷键等现代交互方式
- 提供直观的导航和丰富的信息展示

## 2. 整体布局结构

### 2.1 响应式断点设计

#### 桌面端（≥1024px）：三栏布局
- 左侧：可折叠导航面板（250px）
- 中间：主内容区（自适应宽度）
- 右侧：详情面板（300px，可折叠）

#### 平板端（768px-1023px）：双栏布局
- 左侧：导航面板（可收起为图标模式，60px）
- 右侧：主内容区
- 详情面板：以抽屉形式从右侧滑出

#### 手机端（<768px）：单栏布局
- 底部导航栏（文件/收藏/搜索/设置）
- 文件列表全屏显示
- 详情面板：全屏模态框展示

### 2.2 导航面板组成

#### 树形目录
- 显示完整的文件夹层级结构
- 支持无限层级展开/折叠
- 点击文件夹在主内容区显示其内容
- 右键菜单：打开、在新标签页打开、收藏、重命名、删除

#### 收藏夹区域
- 显示用户收藏的常用文件夹
- 支持拖拽排序
- 支持创建收藏夹分组
- 数据本地存储，同步到服务器

#### 标签页区域
- 显示已打开的文件夹标签
- 支持关闭、拖拽排序
- 每个标签独立的历史记录

#### 存储空间显示
- 显示已用/总存储空间
- 进度条可视化

## 3. 文件操作交互设计

### 3.1 拖拽操作

#### 拖拽上传
- 将文件从系统文件管理器拖入网盘界面即可上传
- 支持多文件同时拖拽
- 显示上传进度和预估时间

#### 拖拽移动
- 在网盘内拖拽文件到目标文件夹
- 支持跨文件夹移动
- 显示拖拽预览和放置提示

#### 拖拽选择

- 支持拖拽矩形框选

### 3.2 右键菜单增强

- 下载
- 重命名

- 复制到...
- 收藏/取消收藏
- 属性
- 删除

#### 文件夹右键菜单
- 打开
- 在新标签页打开
- 重命名
- 移动到...
- 收藏/取消收藏
- 属性
- 删除

#### 空白区域右键菜单
- 新建文件夹
- 上传文件
- 粘贴
- 刷新
- 全选

- 批量下载（打包为zip）

- 批量删除

## 4. 导航系统设计

### 4.1 树形目录

#### 功能特性
- 显示完整的文件夹层级结构
- 支持无限层级展开/折叠
- 点击文件夹在主内容区显示其内容
- 支持键盘导航（上下箭头、左右箭头展开/折叠）

#### 右键菜单
- 打开
- 在新标签页打开
- 收藏/取消收藏
- 重命名
- 删除
- 新建子文件夹

### 4.2 标签页导航

#### 功能特性
- 支持同时打开多个文件夹标签
- 双击文件夹或右键"在新标签页打开"创建新标签
- 标签页支持关闭、拖拽排序
- 每个标签独立的历史记录，支持前进/后退
- 标签页显示文件夹图标和名称

#### 标签操作
- 新建标签
- 关闭标签
- 关闭其他标签
- 关闭右侧标签
- 固定标签

### 4.3 路径栏增强

#### 功能特性
- 显示当前完整路径（如：根目录 > 文档 > 工作）
- 点击任意路径层级直接跳转
- 支持路径栏编辑模式，可手动输入路径跳转
- 路径栏右侧显示当前文件夹操作按钮

#### 路径栏操作
- 点击路径层级：跳转到该层级
- 双击路径栏：进入编辑模式
- 输入路径后按Enter：跳转到指定路径
- 右键路径层级：复制路径、在新标签页打开

### 4.4 收藏夹功能

#### 功能特性
- 将常用文件夹添加到收藏夹
- 支持拖拽排序收藏项
- 支持创建收藏夹分组
- 收藏夹数据本地存储，同步到服务器

#### 收藏夹操作
- 添加到收藏夹
- 从收藏夹移除
- 重命名收藏项
- 创建分组
- 拖拽排序

## 5. 信息展示和预览设计

### 5.1 缩略图支持

#### 图片缩略图
- 支持 jpg/png/gif/webp/svg 等格式
- 生成三种尺寸：小（64px）、中（128px）、大（256px）
- 支持懒加载，按需加载
- 缓存策略：本地缓存 + 服务端缓存

#### 视频缩略图
- 显示视频第一帧缩略图
- 支持常见视频格式：mp4/webm/avi/mov/mkv
- 显示视频时长标记

#### 其他文件类型
- 显示对应文件类型图标
- 图标设计与 Liquid Glass 风格一致

### 5.2 详情面板优化

#### 基本信息
- 文件名称
- 文件大小（友好格式，如：1.2 GB）
- 文件类型（中文名称和图标）
- 创建时间
- 修改时间
- 上传者

#### 图片文件增强信息
- EXIF 信息：
  - 拍摄时间
  - 相机型号
  - 镜头信息
  - 光圈、快门、ISO
  - GPS 位置（可点击打开地图）
- 图片尺寸（像素）
- 色彩空间

#### 视频文件增强信息
- 视频时长
- 分辨率（如：1920x1080）
- 编码格式（如：H.264）
- 帧率
- 比特率
- 音频信息

#### 音频文件增强信息
- 音频时长
- 比特率
- 采样率
- 艺术家
- 专辑
- 流派

#### 文档文件增强信息
- 文档页数
- 文档大小
- 创建者
- 最后修改者

### 5.3 文件属性增强

#### 文件大小显示
- 友好格式：B、KB、MB、GB、TB
- 精确到小数点后一位
- 显示字节数（鼠标悬停）

#### 时间显示
- 相对时间：3小时前、昨天、3天前
- 绝对时间：2024-01-15 14:30
- 鼠标悬停显示完整时间

#### 文件类型显示
- 中文名称：图片、视频、音频、文档、压缩包、代码
- 对应图标
- MIME 类型（鼠标悬停）

#### 文件标签
- 用户自定义标签
- 标签颜色
- 支持按标签筛选

### 5.4 即时预览

#### 预览气泡
- 鼠标悬停在图片/视频上显示预览气泡
- 预览气泡显示文件名和预览内容
- 支持放大查看

#### 键盘预览
- 选中文件后按 Space 键预览
- 支持左右键切换预览上/下一个文件
- 支持 Escape 关闭预览

## 6. 设计风格和视觉效果

### 6.1 Liquid Glass 设计语言保持

#### 毛玻璃效果
- 继续使用 backdrop-filter: blur
- 保持现有的透明度和模糊半径
- 支持亮色/暗色/跟随系统三种主题模式

#### 颜色系统
- 主色调：保持现有的蓝色系
- 强调色：用于选中、激活状态
- 中性色：用于文本、边框、背景
- 语义色：成功（绿）、警告（黄）、错误（红）、信息（蓝）

#### 视觉元素
- 圆角：8px（小元素）、12px（中等元素）、16px（大元素）
- 阴影：轻微阴影用于层次感
- 边框：半透明边框用于分隔

### 6.2 组件设计规范

#### 导航面板
- 毛玻璃背景
- 轻微模糊效果
- 分组标题使用较小字体
- 选中项使用强调色背景

#### 文件卡片
- 悬浮时显示高光效果
- 选中时显示边框
- 拖拽时显示半透明预览
- 文件夹和文件使用不同图标

#### 按钮
- 保持现有的 LiquidButton 样式变体
- primary：主要操作
- glass：次要操作
- ghost：文本按钮
- danger：危险操作

#### 输入框
- 毛玻璃背景
- 聚焦时显示光晕效果
- 错误时显示红色边框

#### 模态框/抽屉
- 毛玻璃背景
- 动画过渡
- 支持 ESC 键关闭

### 6.3 动画和过渡

#### 面板展开/折叠
- 平滑的宽度过渡动画
- 持续时间：300ms
- 缓动函数：ease-in-out

#### 文件选中/取消
- 轻微的缩放和阴影变化
- 持续时间：200ms

#### 拖拽操作
- 跟随鼠标的半透明预览
- 放置时显示动画反馈

#### 标签页切换
- 淡入淡出过渡
- 持续时间：200ms

#### 文件删除
- 向下滑出动画
- 持续时间：300ms

### 6.4 响应式适配

#### 移动端（<768px）
- 更大的点击区域（最小 44px）
- 简化的操作流程
- 底部导航栏
- 全屏模态框

#### 平板端（768px-1023px）
- 适中的信息密度
- 支持手势操作
- 抽屉式详情面板
- 可折叠导航面板

#### 桌面端（≥1024px）
- 完整功能
- 支持键盘快捷键
- 三栏布局
- 右键菜单

## 7. 技术实现方案

### 7.1 组件架构

```
DrivePage (主页面)
├── DriveNavigation (导航面板)
│   ├── TreeView (树形目录)
│   ├── Favorites (收藏夹)
│   └── TabList (标签页列表)
├── DriveContent (主内容区)
│   ├── PathBar (路径栏)
│   ├── Toolbar (工具栏)
│   ├── FileList (文件列表)
│   │   ├── ListView (列表视图)
│   │   └── GridView (网格视图)
│   └── BatchActions (批量操作栏)
├── DriveDetail (详情面板)
│   ├── Preview (预览区)
│   ├── FileInfo (文件信息)
│   └── FileActions (操作按钮)
└── DriveModals (模态框)
    ├── UploadDialog (上传对话框)
    ├── NewFolderDialog (新建文件夹)
    ├── RenameDialog (重命名)
    ├── DeleteDialog (删除确认)
    └── MoveDialog (移动到)
```

### 7.2 状态管理

#### 全局状态（React Context + useReducer）
- 当前路径
- 打开的标签页
- 选中的文件
- 收藏夹
- 视图模式（列表/网格）
- 排序选项
- 筛选条件

#### 状态持久化
- 本地存储：localStorage
- 服务器同步：收藏夹、标签页

### 7.3 API 接口设计

#### 复用现有接口
- GET /drive/files - 获取文件列表
- GET /drive/search - 搜索文件
- POST /drive/upload - 上传文件
- POST /drive/sync - 同步文件
- PUT /drive/files/:id - 更新文件信息
- DELETE /drive/files/:id - 删除文件

#### 新增接口
- GET /drive/favorites - 获取收藏夹
- POST /drive/favorites - 添加收藏
- DELETE /drive/favorites/:id - 取消收藏
- PUT /drive/favorites/reorder - 收藏夹排序
- POST /drive/batch/download - 批量下载
- POST /drive/batch/move - 批量移动
- POST /drive/batch/delete - 批量删除
- GET /drive/thumbnails/:id - 获取缩略图
- GET /drive/attributes/:id - 获取文件属性

### 7.4 性能优化

#### 虚拟滚动
- 使用 react-window 或 react-virtualized
- 处理大量文件时保持流畅
- 动态行高支持

#### 图片懒加载
- 使用 IntersectionObserver
- 按需加载缩略图
- 加载占位符

#### 防抖处理
- 搜索输入：300ms 防抖
- 滚动事件：100ms 防抖
- 窗口 resize：200ms 防抖

#### 缓存策略
- 缩略图缓存：内存 + IndexedDB
- 文件信息缓存：内存
- API 响应缓存：内存
