# LineWeb 前端重新设计规范

## 概述

本设计规范旨在将LineWeb前端从当前的"Liquid Glass Design System"升级为现代实用主义风格，同时保留液态玻璃的视觉亮点。设计采用Vercel Geist的实用主义理念，结合Liquid Glass的玻璃质感和折射效果，创建一个既实用又具有视觉吸引力的界面。

## 设计目标

- **混合方案**：保留Liquid Glass的玻璃质感和折射效果，结合现代实用主义设计
- **实用主义风格**：采用Vercel Geist的干净、高效、功能优先的设计理念
- **双主题支持**：同时支持深色和浅色主题，用户可切换
- **简约动画**：仅必要的状态变化，快速、自然的过渡效果

## 动画和交互

### 动画原则

- **简约**：仅必要的状态变化
- **快速**：`150-200ms` 持续时间
- **自然**：`cubic-bezier(0.25, 0.1, 0.25, 1)` 缓动函数
- **尊重用户偏好**：支持 `prefers-reduced-motion`

### 过渡效果

- 状态变化：`150ms` 淡入/淡出
- 悬停效果：`200ms` 颜色/阴影变化
- 页面切换：`200ms` 淡入

### 交互反馈

- **按钮悬停**：颜色变深，轻微阴影
- **卡片悬停**：阴影提升，轻微上移
- **输入框聚焦**：边框颜色变化，轻微阴影

### 折射效果

- 仅用于重要交互元素（如玻璃按钮、玻璃卡片）
- 轻微的折射变形，不干扰内容可读性
- 性能优化：使用CSS `backdrop-filter` 而非JavaScript

## 性能优化

### CSS优化

- 使用CSS变量管理颜色和间距
- 避免复杂的CSS选择器
- 使用 `will-change` 优化动画性能

### 图片优化

- 使用现代图片格式（WebP、AVIF）
- 实现懒加载
- 响应式图片

### 字体优化

- 使用系统字体栈
- 预加载关键字体
- 使用 `font-display: swap`

## 可访问性

### 颜色对比度

- 确保文字与背景的对比度符合WCAG AA标准
- 提供高对比度模式选项

### 键盘导航

- 所有交互元素可聚焦
- 提供清晰的焦点指示器
- 支持键盘快捷键

### 屏幕阅读器

- 使用语义化HTML
- 提供适当的ARIA标签
- 确保动态内容可访问

## 响应式设计

### 断点

- 移动端：< 768px
